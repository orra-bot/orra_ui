# orra_ui

A configurable design system and component library for **Flutter desktop** (macOS, Windows, Linux) **and the web**. It is built on the widgets layer only, with no Material or Cupertino.

- Three-layer design tokens (primitive → semantic → component) with light and dark themes
- Components: `RaButton`, `RaIconButton`, `RaTooltip`, `RaTextField` / `RaForm`, `RaMenu` (submenus, radio items, context menus), `RaDialog` / `showRaConfirmDialog`, `RaToast`, sidebar widgets, `RaScrollbar`
- Bundled Inter variable font; built-in icon glyphs that you can replace with any icon set

See the [project README](https://github.com/orra-bot/orra_ui#readme) for documentation.
