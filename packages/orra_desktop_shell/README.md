# orra_desktop_shell

The window shell for [orra_ui](https://github.com/orra-bot/orra_ui):

- Frameless window with a solid chrome background, a rounded content panel, and a collapsible sidebar
- macOS traffic lights aligned to the custom 44 px title bar (native plugin)
- Minimize / maximize / close buttons on Windows and Linux
- Window position and size persisted across launches
- Native macOS menu bar and global shortcuts on every platform
- Runs on the web too: same layout, no window buttons, and window-only features become no-ops (`RaShellPlatform`)

See the [project README](https://github.com/orra-bot/orra_ui#readme) for documentation.
